## Visual crop · 2026-09-23

The basic Format section includes Bildausschnitt wählen. A local modal shows the current source image (mirrored when applicable), a visible frame, four 44px corner targets, move/new-selection gestures, keyboard arrows and precise pixel inputs. Areas outside the selection are dimmed. Apply copies exact original source pixels without resampling; cancel leaves the image untouched. Crop changes invalidate export proof and participate in undo/redo. The original source can be restored within the editing session; saved projects retain their current cropped source as before.

Print size can shrink proportionally or retain the previous print width; the prospective dimensions are shown before applying. Symmetric percentage crop remains under advanced tools with explicit per-side wording and a 10% + 10% = 20% removal example. This is rectangular extraction, not automatic person segmentation; the background inside the rectangle remains.

## Android workflow update · 2026-09-22

Five-step navigation, optional advanced controls, readable removal modes, exterior-only default, bounded in-memory undo/redo (including crop), and a collapsible sticky mobile preview. Existing desktop styling, permissions and local-only customer image processing are preserved.

The proof uses the exact raster export canvas or generated SVG; alpha counts describe pixel data, not semantic correctness. Empty results and invalid dimensions block export.
