# Logo Reha Werkstatt Offenburg

Bildmarke: Zahnrad (Werkstatt) mit einer Figur mit offenen Armen (Reha).

| Datei | Verwendung |
|---|---|
| `logo-horizontal.svg/.png` | Standard: Briefkopf, Website-Header |
| `logo-vertikal.svg/.png` | Schilder, Aufkleber, quadratische Formate |
| `logo-negativ.svg/.png` | auf dunklem bzw. farbigem Hintergrund |
| `logo-schwarz.svg/.png` | Einfarbdruck, Fax, Stempel, Gravur |
| `bildmarke.svg/.png` | Favicon, Social-Media-Profilbild |

Farben: Petrol `#0E6E73`, Orange `#F28C28`, Anthrazit `#1F2A30`.
Schrift: Liberation Sans Bold/Regular (SIL Open Font License), in den SVGs in Pfade umgewandelt.
PNGs: 4-fache Auflösung, transparenter Hintergrund (außer Negativ-Variante).

Neu erzeugen: `pip install fonttools playwright`, dann `python3 generate_logo.py` und `python3 render_png.py`.
